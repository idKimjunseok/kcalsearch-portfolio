Android App

앱 주요 기능

5개 영역의 핵심 기능을 Compose 화면 단위로 구현했습니다.

AI 음식 분석 (Measure)

측정 버튼 탭 시 BottomSheet에서 사진 촬영(CameraX) · 갤러리 · 텍스트 검색을 선택합니다. 선택한 입력을 AI 백엔드로 전송해 Gemini · Claude 결과를 동시에 받아 비교 화면에 표시합니다.

끼니별 식단 기록 (Record)

아침 · 점심 · 저녁 · 간식으로 자동 분류하여 날짜별로 저장합니다. 분석에 사용한 음식 이미지를 함께 보관하며 날짜별 영양소를 합산해 표시합니다.

칼로리 통계 (Stats)

주 / 월 / 3개월 / 년 단위 칼로리 그래프와 권장 칼로리 대비 점선을 표시합니다. 선택한 기간의 일 평균 · 총 칼로리 · 기록일 수를 요약합니다.

프로필 · 권장 칼로리

나이 · 성별 · 키 · 몸무게를 입력하면 서버 Harris–Benedict 공식으로 개인 권장 칼로리를 산출합니다. 서버 호출은 fire-and-forget으로 처리합니다.

홈 대시보드 (Home)

오늘의 섭취/잔여 칼로리를 도넛 차트로 시각화하고, 단백질 · 탄수화물 · 지방 영양소 바와 주간 식단 현황을 한 화면에서 확인합니다.

다국어 · 로케일 대응

한국어(values-ko) · 영어(values) 리소스를 분리 관리하며, OkHttp 인터셉터로 모든 요청에 디바이스 로케일 기반 Accept-Language 헤더를 자동 첨부합니다.

코드 컨벤션

CLAUDE.md에 정의된 팀 규칙. ktlint · .editorconfig 기반 자동 적용 (4 spaces, max 100 chars).

금지 사항

  • !! not-null assertion 사용
  • LiveData 사용 (Flow로 대체)
  • GlobalScope 코루틴
  • findViewById · XML 레이아웃
  • 와일드카드 import (import com.example.*)

필수 사항

  • Trailing comma 사용
  • kotlinx.collections.immutable.ImmutableList 사용
  • derivedStateOf · remember로 성능 최적화
  • Composable은 modifier: Modifier = Modifier를 첫 optional 인자로
  • State Hoisting 패턴 준수

Coroutine / Flow 4대 점검

  • 메모리 블로트 방지
  • 생명주기 안전 보장
  • Context 누수 없음
  • 모듈 간 의존성 위반 없음

릴리즈 빌드

  • R8 minify + resource shrinking 활성화
  • Firebase Crashlytics 연동 (CrashlyticsTree)
  • network_security_config.xml으로 cleartext 차단
  • DTO 필드 @SerializedName으로 난독화 보존

FastAPI Server

서버 주요 기능

음식 이미지·텍스트를 입력받아 Gemini와 Claude를 asyncio.gather로 병렬 호출하고 통합 응답을 반환합니다.

두 AI 병렬 호출

asyncio.gather()로 Gemini와 Claude를 동시에 호출해 응답 시간을 최소화합니다. 한쪽이 실패해도 나머지 AI 결과만으로 응답합니다.

다중 입력 지원

JPEG · PNG · HEIC 이미지 업로드와 텍스트 쿼리 두 가지 입력 방식을 지원합니다. HEIC는 pillow-heif로 자동 변환합니다.

API Key 인증 + Rate Limit

X-API-Key 헤더 인증과 IP당 분당 20회 Rate Limiting. API_KEY 미설정 시 로컬 개발 모드로 인증을 건너뜁니다.

다국어 응답

Accept-Language 헤더로 한국어/영어 AI 프롬프트를 분기합니다. 헤더 미전송 시 기본값은 한국어입니다.

Pydantic v2 직렬화

응답 모델을 camelCase alias로 정의해 Android Gson과 @SerializedName 없이 1:1 파싱 가능합니다.

Railway 자동 배포

main 브랜치 push 시 Railway가 GitHub 연동으로 자동 빌드·배포합니다. Swagger UI(/docs)가 포함됩니다.

각 레이어 역할

api
endpoints.py HTTP 라우팅, X-API-Key 인증, Rate Limit 체크, Accept-Language 파싱. 비즈니스 로직 없이 service에 위임.
co
config.py pydantic-settings로 .env의 API 키·모델 ID·커스텀 프롬프트를 로드하는 Settings 싱글턴.
mo
schemas.py Pydantic v2 응답 모델. camelCase alias로 Android Gson과 @SerializedName 없이 호환.
sv
nutrition_service.py asyncio.gather()로 Gemini·Claude 동시 호출. 각 응답을 DetectedFoodItem으로 파싱 후 CalorieResult에 통합.
ut
image_utils.py pillow-heif로 HEIC→JPEG 변환, base64 인코딩 후 AI API 전달 형태로 전처리.
